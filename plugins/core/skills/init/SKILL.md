---
name: init
description: 처음 설치 — 역할에 맞는 저장소를 받고, 플러그인·내 메모 폴더·토큰 파일까지 준비한다. "처음이야", "설치해 줘", "기획자야", "다 넣었어"(토큰 넣은 뒤 확인), "agent 저장소 생겼대"에 쓴다. 사람이 명령어를 치지 않게 한다.
argument-hint: '<역할|저장소> [--name 이름] | add <저장소>'
---

1. `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/init.py" <역할 또는 저장소>` — 역할: 기획자·백엔드·프론트·퍼블리셔·에이전트·운영·문서총괄. 자기 저장소와 `settings.json`이 읽는 저장소가 부모 폴더(`work/`)에 나란히 생긴다. 이미 있는 것은 건너뛴다.
   나중에 저장소가 하나 생겼으면 `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/init.py" add <저장소>`.
2. 출력의 "실패"·"비어있음" 줄이 있으면 그대로 사람에게 보여준다 — 아직 없는 저장소(문서 총괄이 `remote.py create`로 만든다), 만들었지만 아직 `setup`을 안 올린 저장소, 또는 Bitbucket 로그인 문제다. 원격 주소를 지어내지 않고, 빈 저장소에 뭔가를 먼저 올리지 않는다.
3. 출력 끝의 "이제 사람이 할 것"(내 폴더 하나를 열고 '신뢰', 토큰 파일 채우기)을 **사람 말로** 전한다. 신뢰는 보안 확인이라 대신하지 않는다.
5. **내 메모 폴더**도 여기서 생긴다 — `memo/people/<이름>/`을 만들어 올리고, 이름을 `HARNESS_ME`로 각 저장소의 `settings.local.json`에 적는다(그래서 어느 저장소에서든 `/core:note`가 내 폴더에 적는다). 이름은 `git config user.name`을 쓴다. 출력에 "내 이름을 모른다"가 나오면 **사람에게 이름을 묻고** `--name 홍길동`으로 다시 돌린다 — 추측하지 않는다. 팀에서 부르는 이름(예: 길동·철수)으로.

6. **토큰은 대화로 받지 않는다.** 사람이 토큰을 붙여 넣으려 하면 "열어 둔 tokens.txt에 붙여 넣고 '다 넣었어'라고만 말해 주세요"라고 한다. 이미 붙여 넣었으면 그 토큰은 폐기하고 새로 만들기를 권한다. "다 넣었어"를 들으면 `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/init.py" check` — ✗ 줄의 → 안내를 **사람 말로** 하나씩 전한다(값은 출력되지 않는다).
7. 역할을 모르면 묻는다: "기획·백엔드·프론트·퍼블리셔·에이전트·운영 중 어느 쪽이세요?" — 사람이 역할 이름을 정확히 말할 필요는 없다("기획 일 해요" → 기획자).

보고(사람 말로): 받은 것 한 줄 · 내 메모 폴더 · 지금 사람이 할 것(내 폴더 열고 '신뢰', 토큰 파일).
