# 팀에 맞추기

바꿀 곳은 두 파일입니다. 팀 구성(저장소·역할·읽기 관계)은 `team.json`, 원격 주소와 연결 값은 `remotes.json`.

## team.json

저장소마다 담는 것(`purpose`), 주인 역할(`owner`), 읽는 저장소와 이유(`reads`), 폴더(`dirs`·`mkdirs`), 쓰는 플러그인(`plugin`)을 적고, `roles`에 "기획자 → product"처럼 역할과 저장소를 잇습니다. 공개 저장소에는 사람 이름을 넣지 않습니다. 기본값은 저장소 7개입니다.

## remotes.json

| 값 | 무엇 |
|---|---|
| `base` | 팀 저장소들이 있는 원격 주소 (예: `https://bitbucket.org/<워크스페이스>/`) |
| `default_branch` | 기본 브랜치 |
| `jira` | 이슈 트래커 주소(`site`)와 프로젝트 키(`project`) |
| `company_email_domain` | 커밋 메일 검사용 도메인. 비우면 검사하지 않는다 |
| `marketplace` | 팀 저장소 설정에 적을 마켓플레이스 위치 (예: `{"source": "github", "repo": "<계정>/team-harness"}`) |
| `marketplace_add` | 첫 설치 때 `claude plugin marketplace add`에 넘길 값 |

바꾼 뒤 아래를 돌립니다.

```
python3 build.py                      # 플러그인에 새 값 반영 (team.json·remotes.json 둘 다)
python3 sync.py update <저장소 폴더들>   # 팀 저장소의 설정·지도 갱신
```

## 팀 저장소 만들기

```
python3 sync.py new backend --into ../work   # 저장소 골격 하나
python3 sync.py all --into ../work           # 일곱 전부
python3 remote.py create backend product     # 원격 저장소 생성 (Bitbucket)
python3 remote.py setup backend --owners backend-owners   # main 보호·파이프라인
python3 remote.py --dry-run create backend   # 호출할 내용만 보기
```

`remote.py`는 Bitbucket API를 쓰며, 실제 호출은 아직 시험하지 않았습니다.

## 사람이 처음 한 번 할 일

1. 관리자가 플러그인을 팀에 켜 두거나, 각자 `/plugin marketplace add <marketplace_add 값>` 후 역할 플러그인을 설치한다. (둘 다 아직 시험 전)
2. Claude에게 "처음이야, 기획자야"처럼 말한다 — 토큰 파일 `tokens.txt`가 열리고, 안내대로 토큰을 넣고 "다 넣었어"라고 하면 저장소를 받는다.
3. 내 폴더 하나를 열고 '신뢰'를 누른다.
