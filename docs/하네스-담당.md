# 하네스 담당

하네스를 고치는 사람을 위한 메모입니다.

## 고치고 확인하기

| 무엇을 고쳤나 | 그다음 |
|---|---|
| `plugins/core/scripts/` 또는 `templates/` | `python3 build.py` — 역할 플러그인에 복사한다. `python3 build.py --check`로 어긋남이 없는지 본다 |
| `repo-template/`·`sync.py`·`remotes.json` | `python3 sync.py update demo/*` — 시연 저장소에 반영 |
| 스킬·훅·규칙 | 시연(`demo/try.py`)으로 세 창을 다시 돌려 본다 |

시험:

```
python3 tests/test_kit.py        # 회귀 시험 (216개)
claude plugin validate .         # 마켓플레이스
claude plugin validate plugins/core
```

GitHub에 올리면 `.github/workflows/test.yml`이 같은 시험(회귀 시험·`build.py --check`·플러그인 검증)을 돌리고, 깨지면 올린 사람에게 알린다.

## 버전 올리기

1. `VERSION`의 숫자를 올린다.
2. `python3 build.py` — 플러그인과 마켓플레이스의 버전이 함께 바뀐다.
3. `python3 sync.py update demo/*` — 저장소의 `.claude/harness.json`에 버전이 적힌다.
4. 시험을 돌리고 커밋한다. 팀원의 Claude Code는 플러그인 자동 갱신으로 받는다.

## 지키는 것

- 저장소에 스킬·훅·스크립트 복사본을 두지 않는다. 동작은 플러그인에서만 온다.
- 역할 플러그인의 `scripts/`·`templates/`는 `build.py`가 넣는 사본이라 손으로 고치지 않는다.
- 허용 목록(`sync.py`)에 파일을 바꾸거나 지우는 명령을 넣지 않는다.
