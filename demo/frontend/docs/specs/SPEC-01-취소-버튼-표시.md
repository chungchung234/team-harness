# SPEC-01: 취소 버튼 표시

> 시연용 예시 스펙입니다. 프론트 쪽 에이전트가 정책서 product/POL-01과 백엔드 스펙 backend/SPEC-01을 읽고 쓴 모양입니다. 정책서가 바뀌면 이 문서의 에이전트도 다음 말에 알게 됩니다.

## 원천 정책과 대응

| 정책서 수용 기준 | 이 스펙에서 어떻게 구현되는가 | 테스트 |
|---|---|---|
| product/POL-01 A1 — 결제 후 30분 안 취소 | 주문 상세에 취소 버튼을 보이고, 누르면 확인 창 뒤 취소 API를 부른다 | 결제 10분 뒤 화면 → 버튼 보임 |
| product/POL-01 A2 — 배송 시작 뒤 불가 | 취소 API가 "배송 시작됨"으로 거절하면 그 사유를 안내 문구로 보인다 | 거절 응답 → 안내 문구 |
| product/POL-01 A4 — 30분 뒤 버튼 숨김 | 주문 조회의 `cancellable`이 false면 버튼을 그리지 않는다. 화면을 열어 둔 채 `cancellableUntil`이 지나면 버튼을 숨긴다 | 기한 1초 전 열어 둔 화면 → 기한 뒤 버튼 사라짐 |

## 하지 않는 것

- 남은 시간을 초 단위로 세어 보이지 않는다(정책서에 없다).
- 부분 취소 화면은 정책서가 정하기 전까지 만들지 않는다.
