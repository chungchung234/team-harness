# 용어집 — 유비쿼터스 언어

> 용어 | 별칭(한글·영문·약어) | 정의 | 정의 문서

| 용어 | 별칭 | 정의 | 출처 |
|---|---|---|---|
| 취소 | 주문 취소, cancel | 결제된 주문을 사용자가 없던 일로 되돌리는 것. 환불이 따른다 | POL-01 |
| 취소 가능 시간 | 취소 기한 | 결제 완료 시각부터 사용자가 직접 취소할 수 있는 시간 | POL-01 |
| 배송 시작 | 출고 | 물류에 주문이 넘어가 운송장이 생긴 때 | POL-01 |
